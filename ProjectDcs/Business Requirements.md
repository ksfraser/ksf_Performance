# Business Requirements - ksf_Performance

## Project Overview
ksf_Performance provides employee performance reviews, goal tracking, and 360 feedback.

## Integration Dependencies

### Provided To
| Module | Data Provided |
|--------|---------------|
| ksf_HRM | Review history, ratings |
| ksf_Training | Training recommendations |

### Consumed From
| Module | Data Consumed |
|--------|---------------|
| ksf_HRM | Employee, manager data |
| ksf_Training | Training records |
| ksf_Workflow | Review approval |
